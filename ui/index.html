索引来源

搜索索引读 LitePan 网盘,直接走 API(和「存储管理」同源,不需要挂载 strm)。旧版的「strm 目录」模式(/src 挂载)已移除。
点「添加目录」弹出网盘目录树,手动点击选择;选完点「保存」生效。「重建索引」会扫描这里所有目录。
油猴「演员/番号文件夹匹配」会逐个扫这些网盘目录(直接调 LitePan API 建目录树,无需挂载);留空=自动按 STRM 任务源目录。

扫描源目录

扫描这些网盘/硬盘文件夹,缓存两份数据:①演员文件夹信息(目录树快照,加速演员文件夹匹配与定位);②「演员文件夹 + 番号」影片定位索引(含每位演员的影片数量与番号列表)。演员总览与排行榜共用这份扫描结果;留空时回退使用「索引与扫描」里的演员匹配目录。
直接调 LitePan API 建目录树并逐目录登记影片番号,无需挂载;目录改名/迁移会在下一次扫描中自动按「失效 + 新增」处理。

缓存规则

每 天一次
默认关闭。首次安装会自动扫描一次建立缓存;开启后每 N 天自动重建一次;日常匹配优先用缓存,未命中走 arkpan-push 搜索,不会频繁扫盘。
仅用于状态显示与手动重建判断;过期不会自动重扫。

立即扫描

增量扫描按「变更检测」执行:新增/删除/修改的目录才更新缓存,未变化自动跳过,通常几秒到几分钟;全量重建清点所有目录,适合首次建库或怀疑缓存不准时使用。
匹配优先用缓存,未命中会自动调用 LitePan 网盘搜索(1 次接口调用,不扫描目录)。首次使用请点「增量扫描」建立一次缓存;之后新增目录直接在搜索中命中,日常不再扫盘。

用于把演员/影片匹配到你的媒体服务器;各服务互不影响,互不启用。

导出 / 导入配置

把 LitePan 连接、匹配服务、115 推送开关、索引目录、演员目录、登录账号等配置导出成一个文件。更换容器或换机器后，导入这个文件即可恢复，不用重新填一遍。
导出时必须设置一个密码，文件以加密形式保存；导入时需要输入同一个密码。
密码只用于本地加解密，不会上传、也不会存进容器；忘记密码就只能重新导出。旧版未加密的备份文件仍可导入（不需要密码）。
索引数据、演员缓存和头像不在备份里（体积大，可在新容器里重新扫描生成）。
